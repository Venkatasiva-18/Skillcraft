Skill Craft

**Skill Craft** is an e-learning platform designed to help users enhance their skills in programming languages and gaming techniques. The platform provides:

- **Live sessions** to resolve doubts and improve understanding of various programming concepts.
- **Self-paced learning** for topics like Python, Java, JavaScript, HTML/CSS, SQL, and more.
- **Gaming skills improvement**, with techniques and strategies for games like chess, checkers, and more.
- **Interactive chat feature** for instructors and students to communicate easily and effectively.

## Features
- **Programming Courses**: Learn programming languages such as Python, Java, JavaScript, SQL, and more.
- **Live Sessions**: Real-time interaction for doubt resolution.
- **Gaming Techniques**: Learn strategies to play popular games.
- **Instructors' Chat**: Teachers and students can interact seamlessly.

## Setup

### Prerequisites
- Java 8 or higher
- MySQL Database
- Jakarta Library

### Installation

1. Clone the repo:
    ```bash
    git clone https://github.com/Venkatasiva-18/Skillcraft.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Skillcraft
    ```

3. Set up your **MySQL Database** using the `skillcraft_db` and import the necessary tables.

4. Install necessary dependencies (if any).

5. Run the project on your local server.
